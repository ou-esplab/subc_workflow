# SubX Workflow — Input Files Reference

This document describes every input file required by the subc_workflow pipeline, organized by stage. Files are either downloaded, pre-existing archives, or generated by an earlier stage. All paths reference defaults from `config.yaml`.

---

## Configuration Path Keys

| Key | Default | Purpose |
|---|---|---|
| `paths.rt_root` | `/data/esplab/subc-backup` | Real-time forecast download root |
| `paths.hc_root` | `/data/esplab/shared/model/initialized/subx/hindcast` | Hindcast archive root (climatology, percentiles) |
| `paths.out_weekly` | `/data/esplab/shared/model/initialized/subx/forecast/weekly` | Products output root (source for publish) |
| `arraylake.input_root` | `/data/esplab/subc-backup` | Source root for ArrayLake ingest |

---

## Stage 1: Ingest

Downloads real-time SubX forecasts from configured source backends.

Supported sources:
- IRIDL (default): `https://iridl.ldeo.columbia.edu/SOURCES/.Models/.SubC`
- Direct provider endpoints (configurable), including ESRL, GMAO, and ECCC
	paths for shadow-mode rollout.

No local input files are required — data is fetched from the remote server. The downloaded files become the input for all subsequent stages.

**Output of this stage → input for preprocess, products, pycpt, arraylake:**

| File pattern | Format | Content |
|---|---|---|
| `{rt_root}/{GROUP}-{MODEL}/forecast/{VAR}/{VAR}_{GROUP}-{MODEL}_{YYYYMMDD}.daily.nc` | NetCDF4 | Raw daily ensemble forecast. Dimensions: S (start date), M (member), L (lead day), Y (lat), X (lon), optionally P (pressure). Units are native model units. |

---

## Stage 2: Preprocess

Validates that real-time files from the ingest stage are present within the lookback window.

| Input file | Source | Config key |
|---|---|---|
| `{rt_root}/{GROUP}-{MODEL}/forecast/{VAR}/{VAR}_{GROUP}-{MODEL}_*.daily.nc` | Ingest stage | `paths.rt_root` |

**Key settings:**
- `validation.lookback_days` — how many days back to search (default 7)
- `validation.policy` — `warn_on_missing` (default) or `fail_on_missing`

---

## Stage 3: Products

The main forecast generation stage. Requires real-time forecasts, hindcast climatologies, and percentile threshold files.

### 3a. Real-Time Forecast Files

| File pattern | Format | Content |
|---|---|---|
| `{rt_root}/{GROUP}-{MODEL}/forecast/{VAR}/{VAR}_{GROUP}-{MODEL}_{YYYYMMDD}.daily.nc` | NetCDF4 | Daily ensemble forecast. `forecast.py` selects the most recent init date within a ±6-day window around the target Thursday. |

**Config keys:** `paths.rt_root`, `models[].group`, `models[].name`, `models[].vars`, `models[].levels`

**Fallback:** If no file is found within the recency window, that model-variable is skipped with a warning.

### 3b. Hindcast Climatology Files

Used to compute forecast anomalies (forecast − climatology).

| File pattern | Format | Content |
|---|---|---|
| `{hc_root}/{var}{lev}/daily/climo/{GROUP}-{MODEL}/{var}_{GROUP}-{MODEL}_{MMDD}.climo.p.nc` | NetCDF4 | Daily climatological mean for one calendar day. Dimensions: `time` (lead days), `lat`, `lon`. Generated by `static/make_subx_climo.py`. |

**Config keys:** `paths.hc_root`, `models[].vars`, `models[].levels`

**Resolved by:** `_resolve_climo_file()` in `products/forecast.py`

**Fallback:** None — if the file is missing the model-variable is silently skipped.

### 3c. Percentile Threshold Files

Used to compute exceedance probability (probability forecast exceeds the Nth percentile).

| File pattern | Format | Content |
|---|---|---|
| `{hc_root}/{var}{lev}/daily/percentiles/{MODEL}-{GROUP}/{var}_{MODEL}-{GROUP}/{var}_{GROUP}-{MODEL}_{MMDD}.{pct}p.nc` | NetCDF4 | Hindcast percentile values for one calendar day. Dimensions: `month_day`, `L` (lead), `Y` (lat), `X` (lon). Generated by `static/split_subx_percentiles.py`. |

**Example:** `/data/esplab/shared/model/initialized/subx/hindcast/prsfc/daily/percentiles/GEFSv12_CPC-EMC/pr_GEFSv12_CPC-EMC/pr_EMC-GEFSv12_CPC_0528.95p.nc`

**Config keys:** `paths.hc_root`, `exceedance.percentile` (default 95), `exceedance.model_id`, `exceedance.max_fallback_days` (default 7)

**Resolved by:** `nearest_mmdd_threshold()` in `utils/subc_pycpt_utils.py`

**Fallback:** Searches ±`max_fallback_days` days if exact MMDD is missing. If no file found, model is excluded from exceedance products.

## Stage 4: Static (one-time setup)

Generates the climatology and percentile threshold files required by the products stage. Run once per model, or when adding new models.

### 4a. Hindcast Ensemble-Mean Files (input to `make_subx_climo.py`)

| File pattern | Format | Content |
|---|---|---|
| `{hc_root}/{var}{lev}/daily/full/{GROUP}-{MODEL}/{var}_{lev}_{GROUP}-{MODEL}_{YYYYMMDD}.emean.daily.nc` | NetCDF4 | Hindcast ensemble-mean daily fields for one initialization date. Dimensions: `time` (lead days), `lat`, `lon`. Variable name is `{var}_{lev}` (e.g., `pr_sfc`). |

**Source:** Pre-existing hindcast archive — not generated by this workflow.  
**Required years:** 1999–2015 by default (configurable via `--start-year`/`--end-year`).  
**Config key:** `paths.hc_root`

### 4b. GWSC Percentile Source Files (input to `split_subx_percentiles.py`)

| File pattern | Format | Content |
|---|---|---|
| `/data/esplab/gbrown/GWSC/{GROUP}-{MODEL}_{var}{pct}.nc` | NetCDF4 | Monolithic percentile file with `month_day` coordinate (366 entries). Dimensions: `month_day`, `L`, `Y`, `X`. |

**Source:** Pre-computed by G. Brown (GWSC archive) — not generated by this workflow.  
**Config key:** `paths.thresholds_template` (used as reference for source path conventions)

---

## Stage 5: ArrayLake

Syncs real-time forecast files to the cloud repository.

| Input file | Format | Content |
|---|---|---|
| `{arraylake.input_root}/{GROUP}-{MODEL}/forecast/{VAR}/{VAR}_{GROUP}-{MODEL}_{YYYYMMDD}.daily.nc` | NetCDF4 | Same as ingest output. New init dates are appended; existing dates are skipped. |

**Config keys:** `arraylake.input_root`, `arraylake.variables`, `arraylake.skip_models`, `arraylake.model_vars`  
**Credentials:** `ARRAYLAKE_TOKEN` environment variable or `arraylake/.env` file

---

## Stage 6: Publish

Transfers products stage outputs to the web server via SCP.

| Input | Source | Description |
|---|---|---|
| `{out_weekly}/{FCSTDATE}/images/*.png` | Products stage | All forecast panel plots and exceedance maps |
| `{out_weekly}/{FCSTDATE}/data/*.nc` | Products stage | All forecast NetCDF files and manifests |

**Environment variables:** `SUBX_WEB_HOST`, `SUBX_WEB_BASE`, `SUBX_WEB_SSH_KEY`, `SUBX_PUBLISH_SUBDIR`

|---|---|---|---|
| `{rt_root}/{GROUP}-{MODEL}/forecast/{VAR}/{VAR}_{GROUP}-{MODEL}_{YYYYMMDD}.daily.nc` | Preprocess, Products, PyCPT, ArrayLake | Ingest (downloaded) | After ingest |

## Naming Conventions

| Component | Pattern | Example |
|---|---|---|
| Forecast date | `YYYYMMDD` | `20260528` |
| Calendar day | `MMDD` | `0528` |
| Group-Model | `{GROUP}-{MODEL}` | `ECCC-GEPS8`, `EMC-GEFSv12_CPC` |
| Variable | Short lowercase | `pr`, `tas`, `zg`, `rlut` |
| Level suffix | Appended to variable in directory names | `sfc`, `2m`, `200`, `500`, `toa` |
| Variable in hindcast filename | `{var}_{lev}` | `pr_sfc`, `zg_500` |
| Percentile suffix | `{N}p` | `95p` |

---

## Pre-Run Checklist

Before running a forecast date, verify:

- [ ] **Ingest** completed and files exist in `{rt_root}` within the last 7 days
- [ ] **Climatology files** exist in `{hc_root}/{var}{lev}/daily/climo/` for all configured models and variables — run `static/run_all_static.sh --climo-only` if missing
- [ ] **Percentile threshold files** exist in `{hc_root}/{var}{lev}/daily/percentiles/` — run `static/run_all_static.sh --pct-only` if missing
- [ ] `ARRAYLAKE_TOKEN` is set if the arraylake stage is enabled
- [ ] SSH key is accessible for the publish stage
